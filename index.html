Google Sheets Setup
Works offline — no internet needed in the app
1Create a Google Sheet with these column headers in row 1:
Name, Category, Stock, ReorderLevel, CostPrice, SellPrice, Supplier
2Fill in your items. Category must be one of: Electrical Components Power Installation Modules
3In Sheets: File → Download → CSV (.csv)
4In the app: Settings → Import from CSV → pick the file
5Review the preview and tap Import. Items with the same name are updated; new names are added.
Tip: Use Export Stock as CSV first to get your current inventory into Sheets as a starting point.
Requires internet. Works in Chrome and AppsGeyser (with internet permission enabled).
1Create a Google Sheet with headers: Name, Category, Stock, ReorderLevel, CostPrice, SellPrice, Supplier
2Click Extensions → Apps Script. Delete any existing code and paste this:
function doGet(e) {
  const sheet = SpreadsheetApp
    .getActiveSpreadsheet()
    .getActiveSheet();
  const rows = sheet.getDataRange().getValues();
  const hdrs = rows[0].map(h =>
    h.toString().trim().toLowerCase()
     .replace(/\s+/g,''));
  const items = [];
  for (let i = 1; i < rows.length; i++) {
    const r = rows[i];
    if (!r[0]) continue;
    const o = {};
    hdrs.forEach((h,j) => o[h] = r[j]);
    items.push({
      name:         String(o['name']||''),
      cat:          String(o['category']||'Electrical'),
      stock:        Number(o['stock']||0),
      reorder:      Number(o['reorderlevel']||10),
      cost:         Number(o['costprice']||0),
      price:        Number(o['sellprice']||0),
      supplierName: String(o['supplier']||'')
    });
  }
  return ContentService
    .createTextOutput(
      JSON.stringify({ok:true,items:items})
    )
    .setMimeType(
      ContentService.MimeType.JSON
    );
}
3Deploy → New deployment. Type: Web app. Execute as: Me. Access: Anyone. Copy the URL.
4Paste the URL in Settings → Live sync URL and tap Sync.

Cloud Sync Setup
Paste your Firebase config below (see the Setup Guide tab if you haven't created one yet), then choose whether this phone starts a new shop or joins an existing one.
This phone becomes the main copy. A unique Shop Code will be generated — share it with the cashier's phone afterward.
This phone will pull the existing stock, sales, and suppliers from the cloud and start syncing immediately. Local data on this phone will be replaced.
Free Firebase project — about 5 minutes, one-time setup
1Go to console.firebase.google.com and sign in with any Google account.
2Click Add project, give it any name (e.g. "electropro-shop"), and finish creation. Disable Google Analytics if asked — not needed.
3In the left menu, click Build → Firestore Database → Create database. Choose Start in test mode and pick the location closest to you.
4Click the gear icon (top left) → Project settings. Scroll to "Your apps" and click the </> (Web) icon to register a web app. Give it any nickname.
5Firebase shows a code block with firebaseConfig = {"{...}"}. Copy everything inside the curly braces (including the braces) and paste it into the Firebase Config field on the Connect tab.
6Back here: tap Start New Shop, then Connect. You'll get a Shop Code.
7On the cashier's phone: open the same app link, go to Settings → Cloud Sync → Set Up, paste the same Firebase Config, choose Join Existing Shop, and enter the Shop Code.
Security note: "Test mode" allows open read/write for 30 days, which is fine to get started. For longer-term use, Firestore security rules can be tightened later — ask if you want help with that when the time comes.
Free tier covers roughly 50,000 reads and 20,000 writes per day — far more than a small shop needs.
